# 幕後操盤手

2026 首都市長之戰的政治諷刺卡牌遊戲。你是幕後操盤手，替「藍藍路黨・講卍安」或「綠嘻嘻黨・審伯羊」打選戰：用抹黑、造勢、暗樁和網路迷因必殺技（問A答BCD、洋流來襲、國中椅子技……），一路撐到 11/28 投票日。

**直接玩**：打開 GitHub Pages 網址（手機、電腦都可以），第一場會有新手教學。建議開聲音。

## 怎麼玩
- 聲量：造勢會漲，被抹黑會掉
- 反感：抹黑別人會累積，民調時扣票；到 10 會全網炎上、聲量腰斬
- 每兩週民調結算：聲量 − 反感 + 基本盤 2 票 → 選票
- 同一回合連續出牌觸發連擊；陣營必殺卡有必殺技演出
- 四關：黨內徵召戰 → 舊文攻防戰 → 電視辯論會 → 投票日

## 檔案
- `game/index.html` 遊戲本體（單一檔案，原生 JS）
- `game/img/` 卡圖與角色（Codex 內建產圖）
- `game/audio/` 播報員語音（`make_voices.sh` 用 macOS TTS + ffmpeg 生成）
- `convert_images.sh` 原圖 PNG → 網頁用 JPG
- `prompts/` 產圖提示詞
- `video/` 結局大絕招影片腳本
