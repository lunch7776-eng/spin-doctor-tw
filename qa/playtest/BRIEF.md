# 角色扮演試玩：第一次收到連結的朋友

## 你是誰
你是一位 30 歲左右的台灣上班族，有在看政治新聞跟網路迷因，但不是重度遊戲玩家。
朋友在 LINE 丟了一個連結給你，只說了一句「欸我做的選舉卡牌遊戲，玩玩看」。
你在**手機**上點開（iPhone 尺寸 390×844），通勤時間有 5～10 分鐘可以玩。
你**沒看過任何說明、不知道遊戲規則**，所有理解都只能來自畫面上看到的東西。

## 怎麼「點開」
- 正式網址：https://lunch7776-eng.github.io/spin-doctor-tw/
- 如果連不上網，改用本機版本：在 game/ 目錄起 `python3 -m http.server 8977`，開 http://localhost:8977/
- **不要自己啟動 Chrome（沙箱內會失敗）。** 已經有一個開好的無頭 Chrome，用 `puppeteer.connect({browserURL:'http://127.0.0.1:9333'})` 連進去，開新分頁，再用 `page.emulate` / `setViewport` 設成手機尺寸（390×844、deviceScaleFactor 2、isMobile、hasTouch）。結束時用 `browser.disconnect()`，不要 `close()`。
  - 套件位置：NODE_PATH 已指到可用的 node_modules（`import('puppeteer-core')` 或 `require('puppeteer-core')`）
- 你的試玩腳本與截圖只准寫在 qa/playtest/ 底下。**禁止修改 game/ 任何檔案。**

## 試玩方式（要像真人，不是 QA）
1. 每一步都先截圖，**親眼看截圖**（用你的看圖工具）再決定下一步要點哪裡。用點擊/觸控操作，不要直接呼叫遊戲內部 JS 函式來跳關或作弊（讀 DOM 找按鈕座標可以）。
2. 照真人會做的順序：看標題畫面 → 開始 → 選陣營 → 跟著教學 → 打第一場（至少打完 1 場、盡量打到第 2 關）→ 有興趣的話去抽卡、看圖鑑。
3. 一邊玩一邊把「內心 OS」記下來：哪裡看不懂、哪裡覺得好笑、哪裡想放棄、哪裡會想截圖傳給朋友。
4. 遇到卡住超過 3 次嘗試，就照真人反應寫下「我會在這裡關掉」並說明原因，然後再試著繼續。

## 交付：寫進 qa/playtest/FEEDBACK.md（繁體中文）
1. **第一印象（前 10 秒）**：點開看到什麼、想不想繼續玩
2. **試玩日記**：依時間順序，每段附截圖檔名 + 內心 OS
3. **看不懂的地方 Top 5**：每點寫「在哪個畫面、我以為是什麼、實際是什麼」
4. **好玩／好笑的地方 Top 3**
5. **會不會轉傳給朋友？為什麼？** 打 1–10 分
6. **如果只能改 3 件事**：依影響大小排序，每件一句話說要改什麼
7. 技術問題（如果有）：畫面被裁切、按不到、音效沒出來、卡住等，附截圖

寫回饋要誠實、口語、像真的玩家，不要客套。每個抱怨都要附截圖證據。
